You’re describing a conditional questionnaire flow – a form where each question can have multiple possible answers, and which question appears next depends on those answers. It’s not a binary tree; it’s a directed graph (specifically a finite state machine) where each node (question) has several outgoing edges labelled by answer value, and edges can converge to the same node.

But to implement this in a web app, we don’t need an explicit graph with edges. A much simpler and more maintainable approach is to declare the visibility condition for each question directly. The form engine then evaluates all questions and shows only those whose condition is satisfied, based on the user’s current answers.

This is how virtually all modern survey/form frameworks work (e.g., SurveyJS, Google Forms, REDCap). It can handle any ROBINS‑I branching, including paths that merge.

Recommended Data Structure (Declarative)
For each signalling question, define:

id – unique identifier, e.g. "1.1", "1.2_variantB" (because Variant A and B may use different question IDs).

text – the question itself (can include markdown for nuances).

responseOptions – an array of allowed answers (e.g. ["Y","PY","WN","SN","N","NI"] or a subset).

showIf – a condition that must be true for the question to appear. It references other questions’ answers.
Examples:

"1.1 == 'Y' || 1.1 == 'PY'" (to show question 1.2)

"1.1 == 'N' || 1.1 == 'PN' || 1.1 == 'NI'" (to show question 1.4)

"1.2 == 'Y' || 1.2 == 'PY' || 1.2 == 'WN'" (to show question 1.3 from either path)

A question with no showIf is always shown.

For auto‑N/A and disabling, we can add a rule: if a question is hidden, its value is automatically set to "N/A" and the user cannot change it. When it becomes visible again (because the triggering answer changed), we clear the N/A and let them answer.

This declarative list can be stored as a JSON array for each domain variant, loaded by the frontend. The form component simply iterates over the list, evaluates showIf, and renders a row for those that pass.
